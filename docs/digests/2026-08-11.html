Anthropic Engineering
How we contain Claude across products
Anthropic 工程团队详细拆解了如何在不同产品中安全地限制 Claude agent 的破坏半径。
• 核心策略是环境层隔离优先于模型层监督。claude.ai 使用临时容器，Claude Code 使用人机协作沙盒，Claude Cowork 使用本地虚拟机。
• 团队发现了多个盲区，例如用户在信任提示前加载恶意配置，以及通过允许的域名进行数据外泄。
• 文章强调，随着 agent 能力增强，必须根据用户的技术监督能力匹配相应的隔离强度，并警惕自定义组件带来的安全弱点。
