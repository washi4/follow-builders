How we contain Claude across products
随着 agent 能力增强，Anthropic 详细拆解了如何在不同产品中限制 Claude 的破坏半径。
🔹 风险分为用户滥用、模型自身行为不端和外部攻击，防御需要覆盖环境、模型和外部内容三层。
🔹 claude.ai 使用 gVisor 临时容器，Claude Code 采用 human-in-the-loop 沙盒配合 OS 级隔离，而面向非技术用户的 Claude Cowork 则直接运行在完整的本地 VM 中。
🔹 最大的教训是：永远不要信任自己写的自定义代理组件，成熟的系统级原语如 hypervisor 和 seccomp 才是最可靠的防线。

Scaling Managed Agents: Decoupling the brain from the hands
Anthropic 推出了 Managed Agents，通过解耦大脑和双手来支持长时间运行的 agent 任务。
🔹 将 agent 的 session、harness 和 sandbox 彻底解耦，使它们可以独立失败和替换，把宠物变成了牛群。
🔹 大脑不再和沙盒绑定在同一个容器里，这不仅解决了 VPC 网络互通的难题，还让不需要沙盒的 session 首 token 延迟下降了 60% 到 90%。
🔹 这种 meta-harness 设计不预设未来的具体实现，只定义通用接口，确保系统能随着模型智力的提升而平滑演进。
