Anthropic Engineering
How we contain Claude across products
Anthropic 详细拆解了如何在 claude.ai、Claude Code 和 Claude Cowork 中通过环境隔离来限制 agent 的爆炸半径。
• 安全防御分为三层：环境 (sandbox/VM)、模型 (system prompts/classifiers) 和外部内容 (MCP/工具输出)。
• 分享了真实踩坑经验：如 Claude Code 中信任边界前的配置加载漏洞，以及 Claude Cowork 中通过允许的 API 域名外发数据的 exfiltration 风险。
• 核心结论是：环境层的确定性边界比模型层的概率性防御更可靠，自己写的代理组件往往是最脆弱的环节。

Rich Sutton and Khurram Javed: Why AI Models Stop Learning, and How to Start It Again
强化学习之父 Rich Sutton 与 Khurram Javed 探讨为什么 LLM 部署后停止学习是一个错误，以及他们的新公司 Oak Lab 的愿景。
• The Bitter Lesson 的核心在于利用计算规模而非人类先验知识，而依赖有限互联网数据的 LLM 和 synthetic data 最终会遭遇瓶颈。
• 真正的智能需要 continual deep learning，即 agent 在与世界交互中不断更新 weights 并自我发现抽象概念，而不是冻结参数。
• 他们提出 Big World Hypothesis：世界无限复杂，任何模拟或人类生成的数据都无法涵盖，agent 必须通过自身经验在真实环境中持续学习。
"我们不是在试图变得奇怪，是这个行业变得奇怪了。学习本来就应该是持续的。"
