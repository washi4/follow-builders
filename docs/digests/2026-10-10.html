Anthropic Engineering

How we contain Claude across products
随着 agent 能力的增强，Anthropic 分享了如何在不同产品中限制 Claude 的破坏半径。
- 环境层隔离（如沙盒和虚拟机）比依赖模型层监督或人类审批更可靠，因为人类容易产生审批疲劳。
- 针对 claude.ai、Claude Code 和 Cowork 设计了不同的隔离架构，以匹配不同用户群体的技术背景和监督能力。
- 自定义的安全组件往往是系统中最薄弱的环节，成熟的底层隔离技术表现更稳定。
https://www.anthropic.com/engineering/how-we-contain-claude
An update on recent Claude Code quality reports
Anthropic 解释了近期 Claude Code 质量下降的原因，并宣布已全面修复。
- 问题源于三个独立改动：错误调低了默认推理 effort、缓存优化 bug 导致丢失思考历史、限制字数的系统提示词影响了编码质量。
- 所有改动均已回滚，并为所有订阅用户重置了使用额度。
- 未来将引入更严格的系统提示词变更控制和更广泛的评估测试。
https://www.anthropic.com/engineering/april-23-postmortem
Scaling Managed Agents: Decoupling the brain from the hands
Anthropic 推出了 Managed Agents，通过解耦大脑和双手来支持长时间运行的复杂任务。
- 将模型和 harness 与沙盒和工具分离，使容器从宠物变成牲畜，故障恢复更简单。
- 这种架构大幅降低了 time-to-first-token (TTFT)，p50 延迟下降约 60%。
- 支持多大脑和多双手的灵活扩展，为未来更智能的模型和更复杂的工具链做好了准备。
