Anthropic Engineering
An update on recent Claude Code quality reports
Anthropic 详细复盘了近期 Claude Code 质量下降的三个独立原因，并重置了所有订阅者的 usage limits。
• 第一个问题是默认 reasoning effort 从 high 降到了 medium 以减少延迟，导致模型变笨，现已改回 high。
• 第二个问题是缓存优化的 bug 导致旧 thinking 被持续清除，模型在长会话中变得健忘且重复，现已修复。
• 第三个问题是为了减少 Opus 4.7 的 verbose 而添加的 system prompt 意外降低了 coding 质量，现已回滚。

Anthropic Engineering
Scaling Managed Agents: Decoupling the brain from the hands
Anthropic 介绍了 Managed Agents 的全新架构设计，将 agent 的核心组件进行了解耦。
• 将 brain (Claude 和 harness)、hands (sandbox 和 tools) 以及 session (事件日志) 分离，使其可以独立扩展和替换。
• 这种设计解决了单容器架构下的状态丢失问题，让 sandbox 变成了可以随时替换的 cattle，大幅降低了首 token 延迟 (TTFT)。
• 在安全方面，确保 OAuth token 等凭证永远无法从 sandbox 内部被直接访问，防止了 prompt injection 攻击。
https://www.anthropic.com/engineering/managed-agents
