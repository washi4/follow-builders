An update on recent Claude Code quality reports
Anthropic 修复了导致 Claude Code 质量下降的三个独立问题。首先，将默认 reasoning effort 从 high 降为 medium 导致智力下降，现已恢复为高算力模式。其次，一个缓存优化 bug 导致空闲一小时后的 session 在每次交互时丢失历史 thinking 记录，表现为“健忘”，该问题已修复。最后，一个旨在减少 Opus 4.7 冗余输出的 system prompt 更改意外降低了编码质量，现已回滚。目前所有订阅者的使用限制已重置。

Scaling Managed Agents: Decoupling the brain from the hands
