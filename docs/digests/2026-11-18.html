[One Million AI Engineer Special] How Stanford Teaches AI-Native Engineering Mihail Eric, Monaco

Stanford 兼职教授兼 Monaco AI 负责人 Mihail Eric 深入探讨了他在 Stanford 教授的 CS 146S 课程。该课程专注于 AI-native 开发的最佳实践，涵盖 context engineering、agent-ready codebases、agentic code review 以及 software factories 等前沿主题。他强调，学生不仅需要扎实的 traditional computer science 基础，还要学会如何与 coding agents 协作，而不是单纯依赖它们。
