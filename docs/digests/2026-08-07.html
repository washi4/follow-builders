构建可靠的长周期 agent 需要将 context 视为运行时训练数据，并定义明确的行为规范，而非仅仅依赖结果评估。

• Context engineering 本质上是在运行时训练模型，为非编码类 agent 设计清晰的 ontology 和规范文档，就像管理代码库一样重要。
